Projects

Ralph: Sandboxed AI Agent on Hermes

ACTIVE

I deployed Hermes Agent, an open-source agentic framework, as Ralph: a sandboxed AI agent running in an isolated VirtualBox VM, connected to my local LM Studio inference server. I set up the VM sandboxing, the LM Studio integration, and a persistent Telegram control interface. On top of that I built a five-test benchmark suite with a defined scoring rubric to compare agent behavior across model swaps, later reused to benchmark a separate Claude-based agent against the same local models. I also wrote operating constraints for how the agent works after diagnosing real failure modes: a standing rule against delegating any task under five terminal commands, and a full read-then-full-rewrite file protocol adopted after silent write failures showed up in patch-based edits.

Stack
Hermes Agent, LM Studio (OpenAI-compatible endpoint), Telegram Bot API, VirtualBox, Ubuntu, tmux

Atlas RMF Evidence Collection Agent

ACTIVE

A scheduled agent that inventories a Linux host and converts each finding into a NIST 800-53 control implementation statement. Six unprivileged collectors cover Docker inventory, open ports, patch state, user accounts, SSH configuration, and disk encryption, mapped to seven controls. It runs hourly under a sandboxed systemd timer and accumulates evidence in git rather than overwriting it, regenerating a live dashboard from each run's real output. Statement generation started on a local LLM, took 114 minutes per run, and was unreliable, so I replaced it with a deterministic rule engine that completes in under a second with equal or better accuracy and returns NEEDS REVIEW on genuinely undecidable questions instead of fabricating a verdict.

Controls
AC-2, IA-5, AC-17, CM-7, CM-8, SI-2, SC-28
Stack
Python, systemd timers, Docker, NIST 800-53, git, MkDocs

github.com/jwkrick/atlas-rmf-evidence-collector
